# NEXXUS — Nexxathon Registration Portal

NEXXUS Nexxathon Registration Portal is a simple and responsive web portal built for hackathon registration and team management.

## Features

* Team registration and unique team codes
* Join existing teams using a team code
* Team member verification
* Browse hackathon problem statements
* Track-based challenge discovery
* Registration status checking
* Event announcements and updates
* WhatsApp team sharing and group integration
* Responsive design for desktop and mobile
* Admin management support

## Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** REST API
* **Database:** Supabase
* **Integration:** WhatsApp

## Registration Flow

```text
Create Team → Get Team Code → Share Code → Join Team
                     ↓
              Explore Challenges
                     ↓
               Select Problem
                     ↓
                 Build & Submit
```

## Purpose

The portal is designed to make the Nexxathon registration and team formation process simple for participants while providing organizers with an easy way to manage the event.
